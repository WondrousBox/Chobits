# 日常关心模式规划

## 核心目标

- 让桌面精灵在「陪伴」「提醒」「关怀」三方面形成节奏，而不是零散提示。
- 同时覆盖高频健康习惯（喝水、活动、护眼）、时间管理（会议、生日）、情感关怀（节日彩蛋、家庭问候）。
- 模块化实现：所有日常提醒逻辑在 Electron 主进程的独立服务内调度，对外提供统一 IPC API，方便前端配置与可视化。

## 功能矩阵

| 功能块          | 触发策略                                     | 提示渠道                                        | 说明                                                      |
| --------------- | -------------------------------------------- | ----------------------------------------------- | --------------------------------------------------------- |
| 喝水提醒        | 每 60 分钟，09:00-22:30                      | sprite notice + 情绪标签 `reminder`             | 默认模板：喝水、润喉、换杯等多语句随机                    |
| 颈椎/站立提醒   | 每 90 分钟，全天（07:30-22:00）              | sprite notice（warning 级别）                   | 检查上一次活动时间，连续久坐才触发                        |
| 20-20-20 护眼   | 每 50 分钟，屏幕在线                         | sprite notice                                   | 包含 20 秒放松提示，可附带“盯 20 米外”技巧                |
| 深夜守护        | 固定时段 23:30/00:30/01:30                   | sprite notice（warning → error）                | 随时间升级用语，提醒保存/休息/关机                        |
| 会议提醒        | 自定义单次/重复事件（提前 10~15 分钟）       | sprite notice + 可选系统通知                    | 支持「标题+地点/链接+备注」                               |
| 生日 & 家庭关心 | 年度日期（生日、父母生日、纪念日）           | sprite notice（success）                        | 可附加“记得打电话”“给父母发消息”                          |
| 节日彩蛋        | 预置父亲节、母亲节、中秋、春节、除夕、元旦等 | sprite notice（celebrate） + 可触发季节动画 tag | 可关联 `SpriteSeasonalTypes`，播放节日动画                |
| 状态播报        | 每日早晨 09:15 & 傍晚 18:00                  | sprite notice（info）                           | 「今日待办」「天气/温度」「喝水统计」等扩展位，先保留接口 |

## 系统设计

- `DailyCareService`（主进程单例）
  - 维护 `CareRoutine` 列表（默认 + 自定义）
  - 通过主进程 `MainSchedulerService` 为各 Routine 注册调度 job
  - 触发后调用 `sendSpriteNotice`，并将 `lastTriggeredAt/On` 持久化
- `daily-care/storage.ts`
  - 文件 `~/.chobits/daily-care.json` 存储：模式开关、Routine 覆盖、上次触发、用户自定义提醒
  - 对外提供 CRUD：全量读写、更新单 Routine 状态、增删自定义提醒
- Schedule 支持三类：
  1. `interval`：按分钟间隔 + 生效时段 + 星期限制（喝水/护眼）
  2. `fixed`：特定时间点（深夜守护、日间播报）
  3. `calendar`：公历日期或 Nth weekday（父亲节=6 月第三个周日）
- 自定义提醒（会议/生日）
  - 字段：id、标题、日期、时间、重复方式、提前提醒分钟、消息模板、标签
  - 生成 `CareRoutine` 并纳入同一调度
- IPC API（`daily-care:*`）
  - `getSnapshot`：整体配置、运行状态
  - `updateSettings`：总开关 + Routine 层开关、间隔
  - `upsertCustomReminder` / `removeCustomReminder`
  - `triggerNow`：调试或强制触发

## 模式节奏（默认）

1. **晨间问候**（09:15）→ 今日计划/喝水目标。
2. **日间循环**：`喝水 (60m)` → `护眼 (50m)` → `站立/拉伸 (90m)` → 交错执行，避免同分钟多次提醒。
3. **午后关怀**：14:30 点名提醒「补充水果/午后提神」。
4. **傍晚总结**（18:00）→ “今日已工作 X 小时”“喝水 Y 次”。
5. **深夜守护**（23:30+）→ “保存进度/准备休息/关闭电脑”。
6. **节日彩蛋**：当天 09:30 发送预设祝福，并可触发季节动画。

## 下一步扩展接口

- 与系统/传感数据联动：待接入 `powerMonitor.getSystemIdleTime()`、蓝牙站立桌等。
- 前端设置页：使用 `dailyCare` IPC 渲染开关、预设模板、自定义列表。
- 数据回流：统计每条 Routine 的触发次数、用户交互（是否点了“知道了”）。
